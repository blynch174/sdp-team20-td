# Dataset Card for EV FSAE Telemetry Dataset

## Dataset Summary

This dataset contains EV Formula SAE telemetry exported as CSV files from multiple test days in 2025.
Each row is a timestamped telemetry sample. Files are grouped by event date.

## Dataset Structure

- `2025-06-14/` (4 files)
- `2025-06-21/` (1 file)
- `2025-07-12/` (10 files)
- `2025-07-26/` (7 files)
- `2025-08-01/` (5 files)

All files follow the naming pattern:

- `YYYY_MM_DD-XX.csv`

## Data Format

- File format: CSV
- Column count: 79 columns in all files

## Citation

If you use this dataset, please cite this repository and the EV FSAE team that collected the telemetry.
