# Data notes: the 2025-07-12 AiM logs

The ten CSVs in [`data/raw/2025-07-12/`](../../data/raw/2025-07-12/) are raw AiM logger exports from the CT-16EV, all recorded on **Saturday, July 12, 2025** (comment: "Mock AutoX Motor Tune Testing", driver Jack_Louis). They are the same runs Team 19 called `2025_07_12-01` … `-10`, just with different file names.

## File format

| Line | Contents |
|---|---|
| 1–14 | Metadata: format, vehicle, driver, comment, date, time, sample rate (**20 Hz**), duration, etc. |
| 15 | Column header: `"Time"` plus 78 channels (79 columns in total) |
| 16 | Units (`s`, `km/h`, `g`, `°C`, …) |
| 17 | Blank |
| 18+ | Data, one row every 0.05 s |

Load with pandas:

```python
import pandas as pd
df = pd.read_csv(path, skiprows=list(range(14)) + [15], low_memory=False)  # blank line 17 is skipped automatically
df = df.apply(pd.to_numeric, errors="coerce")
```

`backend/mock/mock_dms.py` (`DATA_SOURCE=csv`) finds the header row by itself and replays a file in real time.

Team 19's own loader (`skiprows=[1]`) expects their cleaned Hugging Face copies (`jobegets/ev-fsae-testing`), **not** these raw files.

## Things to know before modeling

- **Most fault rows happen with the car stopped.** In 807, 808 and 809, 82–94% of the fault rows are while stationary: the BMS cuts discharge, then the car stops. Filtering to moving rows hides most of each fault event.
- **806 never moves.** It is 951 s of a stationary car. Team 19 dropped ten sessions like this across the season.
- **The faults cluster with heat and low charge.** 808 (55 °C, 40% SOC) has the most moving faults. The sessions with no faults peak at 46–48 °C.
- **This is one day of testing on one track with one driver.** Models trained only on these files won't generalise to other conditions; Team 19 hit exactly this problem.
- **The front brake pressure sensor looks dead.** `FBrakePressure` sits at about −19 bar in every file, even while the car is moving. Check with FSAE before using it.
- **Rear brake pressure barely tracks deceleration.** Rear pressure (0–22 bar) correlates weakly with deceleration in a quick check (|r| mostly < 0.3 against `InlineAcc` or GPS-speed change), so calibration or IMU noise needs a look before any brake model.
- **No regenerative braking.** `Torque Feedback` is never negative, so all braking is friction.
- **Pack temperature rises steadily within a session.** It climbs from 28 to 46 °C in 801, for example, and has fine resolution (up to about 200 distinct values per session), so it's a good candidate for forecasting.
- **The full 2025 season is on Hugging Face.** Team 19's table lists 27 sessions, from June 14 to August 1, 2025, in `jobegets/ev-fsae-testing`.
- **Channels that exist (useful for Year 2 targets):** `FBrakePressure`, `RBrakePressure`, `BrakeBias`, `RBrakePressCorr`, `Throttle Pos`, IMU (`InlineAcc`, `LateralAcc`, `VerticalAcc`, `RollRate`, `PitchRate`, `YawRate`), GPS (speed, lat/long, heading), plus the battery and inverter channels.
- **Channels that don't exist:** tire temperature, tire pressure, suspension travel, steering angle. These need the new sensors from OWL's deck.
